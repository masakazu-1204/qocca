# Qocca トップページ 刷新デザイン案 (2026/7/4)

> frontend-design スキル全開・「AI感ゼロ・上質でワクワク」挑戦便。
> 3案とも単体で開ける self-contained HTML。画像は全て自社アセット(feature-cards / クオッカSVG)。
> 本番 home.tsx は未変更。King 選定後に別便で実装。

## 案A「余白の雑誌」 (home_draft_A.html)
- **コンセプト**: Qocca を「動物と暮らす人の文芸誌」に見立てる。Kinfolk 直系のエディトリアル
- **タイポ**: Fraunces (欧文セリフ・オプティカルサイズ可変) × Shippori Mincho
- **AI感の消し方**: 誌面グリッド(非対称 7:5)、マストヘッド+号数表記、写真に PHOTO 001 キャプション、クオッカは「編集長の署名」として写真の隅に小さく手描きの温度
- **#F5A94A**: 蛍光ペンの下線・番号・罫線のみ。ベタ塗りゼロの最上級の抑制
- **一撃**: 巨大マニフェスト・タイポグラフィ(「あたりまえに開くアプリへ」)
- **狙う感情**: 「上質。ちゃんとしたブランドだ」= 信頼と品

## 案B「一撃のオレンジ」 (home_draft_B.html)
- **コンセプト**: Apple/Aesop 級のミニマル。ほぼ生成り一色で進み、中盤に**全画面 #F5A94A のマニフェストセクションが一度だけ**現れる(D2C の一撃)
- **タイポ**: Libre Caslon Text (イタリック活用) × Zen Old Mincho × Zen Kaku Gothic New
- **AI感の消し方**: 100svh の静かな巨大タイポHero、写真が語る3枚扉(テキスト最小)、オレンジ面の中でクオッカが回転軌道リングと浮遊アニメで"祭壇化"
- **#F5A94A**: 一撃セクションに全量投下。他はホバーとアクセントのみ → 出会った瞬間の衝撃が最大化
- **狙う感情**: 「洗練の極み → うわっ(オレンジ) → 深呼吸」= 記憶に残る緩急

## 案C「クオッカの号外」 (home_draft_C.html)
- **コンセプト**: 「街ができました」を号外新聞/チケット風に祝う。クオッカ市長が完全主役
- **タイポ**: Fraunces 900 (極太エディトリアル) × Shippori Mincho 800
- **AI感の消し方**: 傾いたチケットカード(rotate -1.4°〜0.8°)、ポラロイド写真(ランダム回転)、ハードシャドウ(5px 5px 0)、街並みシルエットの上で跳ねるクオッカ市長+「市長(せかいいち幸せな動物)」タグ、住民票カード型CTA
- **#F5A94A**: 街並みシルエット・CTAボタン・マーカー下線・カードの落ち影に計画的大量使用(but 全てエッジの効いた形で)
- **一撃**: ヒーロー下部のオレンジ街並み+跳ねる市長 / 黒帯マニフェスト(ストロークテキストのマーキー)
- **狙う感情**: 「たのしそう!今すぐ入りたい」= ワクワク最大

## クマ推し
**B をベースに、C のクオッカ市長(ヒーロー下の街並み+跳ねる市長)を移植したハイブリッド**。
理由: Bの「静→一撃」の緩急が「洗練されてるのに心が動く」の答えそのもの。ただしBは真面目すぎる寸前なので、Cで一番愛される発明(市長)を持ち込むと、上質×ワクワクが両立する。

## 実装方針 (選定後・別便)
1. 選定案の Hero + 導線3枚 + 一撃セクションを home.tsx の新コンポーネント群として実装 (SectionHeroV2 等・既存は温存し1行切替=可逆)
2. フォント追加は index.html の Google Fonts 1行 (Fraunces or Libre Caslon)
3. 段階適用: Hero だけ先行 → 反応見て下層セクション → 全面移行
4. 写真素材: feature-cards 転用で開始 → 実写素材(King撮影/生成)に順次差し替え
