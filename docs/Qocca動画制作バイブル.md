**推奨A なら、今の広告費とほぼ同額(月¥35,100)で毎日3本が回る。**

## 16-11. ★ミーム型の作り方(2026/8/4 King指摘「オチがない」を受けて)

### 失敗から学んだこと
最初に作ったミームは**オチが無かった**。原因は2つ:
1. **映像に裏切りが無い**(おねだり→食べる→おねだり = 予想通り)
2. **テキストが最初から最後まで出っぱなし** ← オチは「後から出る」から効く

→ `add-meme-text.mjs` を **v2で時間区間指定に対応**させた(`--seg "開始,終了,位置,テキスト"`)。

### ★オチの型(これに沿って作る)

```
0〜3秒   フック    状況を提示。「え？」と思わせる
3〜5秒   タメ      期待を作る(まだテキストは前半のまま)
5〜10秒  裏切り    ★映像が変わる + テキストが切り替わる = オチ
```

**映像とテキストの両方が同時に変わること。**片方だけだと落ちない。

### 使える型(汎用・使い回せる)

| 型 | 構造 | 例 |
|---|---|---|
| **宣言→即破り** | 真剣に宣言 → 3秒後に破ってる | 「今日からダイエットします」→「3秒後」 |
| **建前→本音** | よそ行きの顔 → 素の顔 | 「しつけは完璧です」→「散歩のリードを見た瞬間」 |
| **1匹だけ違う** | 全員が同じ行動 → 1匹だけ違う | 「散歩いく人ー！」→「ラム(2歳):」 |
| **自信→失敗** | ドヤ顔 → やらかす | 「猫は犬より賢いんです」→ 段ボールに挟まる |
| **期待→現実** | 飼い主の理想 → うちの子の現実 | 「思い描いていた散歩」→「実際」 |

### 制作上のコツ(実測)
- **ミームは無音で生成する**。テキストが主役なので声は不要。
  → **生成が1分で終わる**(音声つきは3〜4分)。数を打つ形式に向く。
- ショートは**音を消して見る人が多い**。テキストが読めれば成立する。
- クリップは**5秒×2**で十分。10秒あればオチまで作れる。
