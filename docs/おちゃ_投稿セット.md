## 投稿するときの手順 (Instagram)

1. リールとして動画をアップ
2. **音源はアプリ内でトレンドから選ぶ**(動画側の音は環境音なので、消すか小さくする)
3. 上のキャプション + 共通の締めを貼る
4. カバー画像は、いちばん表情が出ているコマを選ぶ

Threads / X には同じ本文を短くして流用してよい。
X は 140字なので、共通の締めを外して本文だけにする。
