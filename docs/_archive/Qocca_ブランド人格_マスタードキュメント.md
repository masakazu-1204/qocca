## 🌌 Phase 5+ の決定的機能 (ちゃぴ提案・採用予定)

### 「季節の記憶」機能

```
ちゃぴ言葉:

"Qoccaって、時間 との相性がかなり良い。
 例えば：
 - 去年の今日
 - 初めて迎えた夏
 - 最後の冬
 - 毎年同じ場所
 
 みたいな、積み重なる記憶 かなりQoccaっぽい"
```

### 実装案 (Phase 5、2027年予定)

```
- "今日は○○ちゃんを迎えてから1年目です"
- "去年の今日、こんな写真を残していました"
- "初めての夏、覚えていますか"
- "あの日から、毎年ここに来ています"

→ うちの子との時間が "積み重なる" 体験
→ SNS にはできない、Qocca だけの価値
→ "亡くなった後の記憶保管場所" への布石
```
