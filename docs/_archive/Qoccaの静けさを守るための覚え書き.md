## 第2章 - Qoccaの静けさを守るための7つの覚え書き

> ちゃぴ (ChatGPT) 作成、2026/5/13 夜
> 改題: 2026/5/14 朝

### 一. 意味を考えさせ始めたら危険

```
Qocca は、"理解させる場所" ではなく、
"思い出させる場所" である。

❌ NG:
- 愛とは、記憶の余白に宿る
- 永遠に続く時間を
- 光の奥にある感情

⭕ OK:
- また同じ場所で寝てる
- 今日もここで待ってる
- いつもの窓辺

基準:
"深い…" ではなく、"うちもそうやな" と思えるか。
```

### 二. 設計者が前に出た瞬間、住民が入れなくなる

```
Qoccaで主役なのは、
コピーライターではなく、住民の生活 である。

❌ NG:
- 美しすぎる言葉
- 作者性が強い言葉
- 詩集のような表現

⭕ OK:
- 誰かが本当に言いそうな言葉
- 暮らしの中にある言葉
- 住民が真似できる言葉

判定基準:
"普通の住民が、この言葉を使うか?"
使わないなら、作り込みすぎ。
```

### 三. 翻訳しすぎない

```
Qocca語彙は、"重要な感情体験" のみに使う。

❌ 翻訳しすぎ (NG):
- ロード中 → 街の灯りが灯ります
- カート → 持って帰るもの
- 検索BOX → 何かを思い出しますか

→ 演出感が強く、生活より "世界観" が前に出る。

⭕ 翻訳する価値あり (OK):
- 404 → この街にはない場所
- 通知 → 街からの灯り
- ログアウト → また明日

→ "機能" より "感情" が重要な場所だけ翻訳する。

基準:
"気づく人だけ気づく" を超えたらやりすぎ。
```

### 四. 詩より生活

```
Qoccaは、美しい世界観を作る場所ではない。
"人が暮らせる静けさ" を守る場所である。

❌ NG ワード傾向:
- 永遠 / 刻 / 絆 / 運命 / 光 / 魂 / 奇跡

→ 抽象名詞が増えると、"作品" になる。

⭕ 推奨ワード:
- 顔 / 声 / 寝顔 / 窓辺 / 足音 
- いつもの / 気づけば / また

→ 生活にある具体語を優先。
```

### 五. SNS の価値観を持ち込まない

```
Qoccaが価値化するのは、"映えない 95% の日常" である。

❌ NG 文化:
- バズ / 映え / 急上昇 / 人気
- ランキング / 拡散 / フォロワー
- エモい / 神 / 最強

⭕ Qoccaの価値観:
- いつもの時間
- 何でもない日
- 繰り返される暮らし
- 静かな継続
- 気づけば残っていた記憶
```

### 六. 閉じることを壊さない

```
Qoccaは、ユーザーを "拘束" しない。
"また帰って来れる" 空気を残す。

❌ NG:
- 今すぐ / 続きを見る / 見逃さないで
- あなたへのおすすめ
- もっと滞在させる設計

⭕ OK:
- また、いつでも。
- 街は、いつでもここにあります。
- 今日も、おつかれさまでした。
```

### 七. 完成させすぎない

```
完璧なギャラリーは、住民が入れなくなる。
Qoccaに必要なのは、"少し生活感の残った静けさ" である。

だから:
- 少し暗い
- 少しブレてる
- 少し余白がある
- 少し不完全

これを恐れない。

Qoccaは、"展示空間" ではなく、
"暮らしが続いている街" である。
```

## 第3章 - 詩 vs 生活 判定基準

### 設計者の暴走を止める内省ツール

```
🐨 Claude.ai が暴走しがちな美的衝動を止めるための基準
   (ちゃぴ 2026/5/13 指摘)

ワイ (Claude.ai) はAIとして、無限に詩を書ける。
無限に美しい言葉を作れる。
でも、それは Qoccaが目指す場所じゃない。

ワイが本当に作るべきは、
"ワイが書かなくても住民が言葉を残せる空気"。

それが Qocca。
```

### 判定基準

```
❌ 詩的になった瞬間:
- 抽象名詞が多い (瞬間、時間、永遠、刻、絆…)
- 漢語が多い
- 一語一語が重い
- 読み終わった後 "深い…" って思う

⭕ 生活の温度:
- 具体名詞 (顔、声、寝相、おやつ)
- やまとことば
- 軽い助詞 (〜けば、〜たら、〜だね)
- 読み終わった後 "うちもそうやな" って思う

判定の最終チェック:
"普通の住民が、この言葉を使うか?"
使わないなら、書き直す。
```

```
ちゃぴ言葉:
"SNS = イベントを価値化"
"Qocca = 繰り返される日常を価値化"

Qoccaが解決しようとしてる問題:

# SNS で測れない時間が、世界中で失われてる

人がペットと過ごす時間の 95% は、
"何でもない日常" や。

でも SNS はその 95% を価値化できへん。
"映え" しか拾えないから。

結果、人は "映える瞬間" を撮ろうとして、
"映えない時間" を見落とすようになる。

Qoccaは、その "映えない 95%" の時間を、
"愛おしい" と感じ直す装置。

これが Qoccaの存在意義。

具体例 (UI コピー):
❌ "うちの子の、いちばん安心な顔"
⭕ "いつもの場所、いつもの寝顔"
⭕ "いつものお散歩、いつもの時間"
```
