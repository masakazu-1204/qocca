## 📖 ResidentDiaries の哲学 (重要更新)

```
ちゃぴ言葉:

"Qoccaに必要なのって、
 文学 じゃなく、生活 やと思う。

 例えば:
 - 今日は少しだけ元気だった
 - 最近、この場所で寝る
 - ご飯の音だけは絶対聞こえる
 
 これぐらいが、逆にリアル。"
```

### 設計方針

```
❌ 求めないもの:
- 長文ブログ
- 文章力
- 完成度
- バズる内容

✅ 求めるもの:
- 3行の生活
- 1枚の写真
- 思い出した時の言葉
- リアルな日常

→ "うまい文章" より "生活の温度"
→ Substack 風だが、もっと "日記" に近い
```

### 投稿UI 案 (Phase 6 検討)

```
[1枚の写真]
[3行までのテキスト]
[時刻]
[投稿]

→ シンプル、強制力なし
→ "月1" "季節ごと" "思い出した時" でOK
→ 連投ボーナスや競争要素ゼロ
```
