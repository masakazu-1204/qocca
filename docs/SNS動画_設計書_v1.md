# Qocca SNS動画 設計書 v1

> 2026/8/4 作成。King指示「収益化も狙える動画にしたい。犬猫が話す・ふざける・感動系」を受けて。
> 方針決定済み: **B案(SNSはふざけ枠 / サイトは静けさ)**、画質は**720pに引き上げ**。

---

## 0. この設計書の結論(先に3行)

1. **一発ネタをやめて「同じキャラの連載」にする。** 参考2本が伸びてるのは全部これ。
2. **主役の柴犬が、Qoccaに実在する場所へ出かける**構成にする。ネタが5,000箇所ぶん無限に湧く。
3. 画質は **fast/720p(17.5クレジット)**。1,802クレジットで**約103本**。

## 1. 実測データ(2026/8/3 検証済み)

| 項目 | 実測値 |
|---|---|
| 生成基盤 | Higgsfield **ローカル連携(MCP)経由** ※REST APIは別財布で残高0。**課金不要** |

| 単価 | fast/480p **7.5** / fast/720p **17.5** / std/720p **22.5** クレジット |
| 生成時間 | 約1分 |
| 出力 | 5秒 / 9:16 / **音声つき** / 約1.2MB |
| 残クレジット | **1,802.5**(Maxプラン) |

**採用: fast/720p = 17.5クレジット → 約103本ぶんの在庫。**
480pはリールで粗さが出るため見送り(Kingの判断)。

## 2. 参考動画の分析 — なぜ伸びるのか

| | 柴犬はるの1日 | 血液型あるある AI犬の学校生活 |
|---|---|---|
| 形式 | 子育て日記(連載) | あるある系(キャラ類型) |
| 共通の勝ち筋 | **①同じキャラが毎回出る ②日本文化ネタ ③`#ai生成` を隠さない** | 同上 |

### ★ここが今のQoccaと決定的に違う

既存の `sns-neta` 画像54枚(27ネタ×2案)は、**パグのヨガ / 秋田犬の相撲 / ハムスターの寿司…と全部バラバラの動物**。
一発ネタとしては面白いが、**キャラが定着せず、チャンネル登録に繋がらない**。

> **一発ネタ = 再生される / 連載 = フォローされる**
> 収益化(=継続的な流入)を狙うなら、後者に構造を変える必要がある。

## 3. ★キャラクター設計

### 主役: 柴犬「**そら**」(仮)

| 項目 | 設定 |
|---|---|
| 種類 | 柴犬(日本で最も認知が高い・既存画像も2枚ある) |
| 性格 | まじめだけど、ちょっとズレてる。食いしん坊。 |
| 声 | **子供っぽい高めの声**(King指定)。舌足らずで、たまに敬語が変 |
| 一人称 | 「ぼく」 |
| 口癖 | 「〜だとおもうんだ」「…しらんけど」(関西の血) |
| 立ち位置 | **Qoccaの街の住人**。おでかけが好き |

### なぜ柴犬か
- 海外にも刺さる(#shibainu は世界共通タグ)
- 既存画像に2枚ある(`neta_20_shiba_dagashi` / `neta_21_shiba_bandai`)
- 参考動画①と同じ土俵 = 需要が実証済み

### 脇役(第2弾以降)
- **黒猫「よる」** — そらの相棒。毒舌でクールだが優しい。低めの落ち着いた声
- **クオッカ(Qoccaマスコット)** — 街の案内役。たまに出るレア枠

> ⚠️ キャラの見た目を毎回そろえるのが最大の技術課題。
> → Seedance 2.0 は **identity保持(reference image)が売り**のモデル。
> **キャラ基準画像を1枚固定**し、毎回それを `start_image` に使うことで見た目を維持する。

## 4. シリーズ形式(3本柱)

### ★A. 「そらのおでかけ日記」 ← **本命**

**Qoccaに実在する施設・散歩スポットへ、そらが出かける。**

- ネタ元: `pet_facilities` **3,525件** + `pet_walker_spots` **1,551件**
- **ネタが枯れない**(5,000箇所以上)
- **そのままQoccaの宣伝になる**(概要欄に実在の場所へのリンク)
- 例: 「きょうは大阪のトリミングサロンにきました。ぼく、シャンプーきらいなんだ。」

| 強み | 説明 |
|---|---|
| 独自性 | **他の誰も真似できない**(5,000件のDBはQoccaだけの資産) |
| 収益動線 | 動画 → 概要欄 → `/welcome/youtube/facilities` → 登録 |
| SEOとの相乗 | 施設ページ(既にSEO実装済み)への流入も増える |

### B. 「そらの◯◯あるある」

- 参考動画②の型。共感で伸びる
- 例: 「犬あるある:飼い主が出かける音、ぜんぶ覚えてる」
- 血液型/星座など**日本人が好きな分類**と組み合わせる

### C. 感動枠(月1〜2本)

- 保護犬・別れ・はじめての海 など
- **ここだけは静けさ世界観に寄せる**(サイトと地続きにする)
- 例: 「ぼくがこの家にきた日のこと、おぼえてる」

## 5. 声の設計(King指定: 子供っぽい)

Seedance 2.0 の `generate_audio: true` は**ネイティブ音声を生成**するが、**声色を直接指定できない**。

### 対策2案

| 案 | 方法 | 長所 | 短所 |
|---|---|---|---|
| **①プロンプト誘導** | prompt に `childlike high-pitched voice, innocent tone` 等を書く | 追加コストゼロ・1工程 | 声が安定しない可能性 |
| ②音声を別生成 | 動画は無音生成 → TTSで子供声を作り → 合成 | **声が完全に安定** | 工程が増える・別コスト |

**まず①で3本試し、声がブレるなら②へ。**(②に必要な `generate_audio` ツールは連携済みで使える)

## 7. 必要な画像(ここが次の作業)

### ★最優先: キャラ基準画像

| 用途 | 内容 | 枚数 |
|---|---|---|
| **そら 基準画像** | 正面・全身・自然光・無地背景。**これが全動画の顔になる** | 3案作って1つ選ぶ |
| そら 表情差分 | 笑顔 / 困り顔 / 寝顔 | 3 |
| よる(黒猫) 基準画像 | 同上 | 3案→1 |

**生成方法**: 既存の `scripts/generate-neta-batch3.mjs` と同じ fal.ai FLUX 2 Pro。
プロンプトに一貫性のある特徴(毛色・首輪・目つき)を固定して書く。

### シーン画像(おでかけ日記用)

**既存の `petwalker` バケット 1,612枚がそのまま使える。**
→ 風景画像 + そらの基準画像 を Seedance の reference に渡して合成する。

## 8. 制作パイプライン(全部つながってる)

```
① キャラ基準画像を作る            … fal.ai FLUX 2 Pro (scripts/)
        ↓
② シーン画像 or petwalker既存画像 … 既に1,612枚ある
        ↓
③ Seedance 2.0 で動画化           … Higgsfield MCP / 17.5クレジット / 約1分
   (start_image=キャラ, prompt=セリフ+動き, 9:16, 音声あり)
        ↓
④ Supabase Storage に保存         … sns-neta バケット
        ↓
⑤ sns_video_assets に登録         … 動画プール(実装済み)
        ↓
⑥ 自動投稿                        … post-video-to-threads / -instagram (実装済み)
        ↓
⑦ YouTube Shorts                  … 当面Kingが手動で予約投稿
```

**⑤⑥は既に完成・本番実証済み。**③④を繋げば全部つながる。
