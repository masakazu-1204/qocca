# ショート動画 10本 企画書 v1 (2026/9/21)

TikTok / リール / YouTube Shorts 用。15〜30秒 / 9:16。
**「Qocca を宣伝する動画」ではなく「おもろい・かわいい・ちょっと泣ける → これ Qocca やったんや」の順番。**

```
配分     ① 面白い・バズ狙い 5本 (70%)   ② 感動・共感 3本 (20%)   ③ Qocca 紹介 2本 (10%)
制作     Higgsfield: 静止画 Nano Banana (1) → Seedance 2.0 Mini 5秒 (12.5)。2.5 は使わない
セリフ   犬猫はしゃべらない。セリフは全部テロップ (口パクは作らない)
人       手・後ろ姿・シルエットまで。顔は出さない
服       「服が本体」のネタ (会社員・エプロン) は着せる。それ以外は裸のほうが強い
画面     スマホの Qocca 画面は AI に描かせない。本物の画面収録を ffmpeg で 1カット差し込む (= Qocca の正体バレの瞬間)
締め     最後の 2〜3秒だけ Qocca。build-cm.mjs の締めカード (コピー + ロゴ)
テロップ Zen Kaku Gothic New Medium / 64px / 下から3割
```

各本の予算目安: 15秒 = 3カット 37.5 / 30秒 = 6カット 75 (+撮り直し 1〜2本)。10本で約 600 クレジット。
