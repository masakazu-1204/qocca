### 2. クリエイターへの敬意 (Respect for Creators)

```
ペットのために、心を込めて作品を作るクリエイターたちがいる:
- うちの子の似顔絵を描く作家
- 羊毛フェルトでうちの子を作る作家

- メルカリ: 価格競争
- 楽天: 大量生産品

→ Qocca は "ペット特化の街"
→ クリエイターが息を吸える場所
→ 「販売価格そのまま手取り」のメッセージ

### 3. コミュニティの力 (Power of Community)

```
1人で飼ってる人の孤独:
- うちの子の自慢を聞いてくれる人がいない
- 同じ犬種・猫種で話せる人がいない
- 病気・しつけの悩みを話せる人がいない

→ Qocca は "うちの子を愛してる人が集まる街"
→ 広場 (Community) で語り合える
→ 1人じゃないと感じられる場所

## 🎨 世界観 (静けさ最優先)

### 言葉のトーン

```
✅ 使う言葉:
- 「うちの子」 (← "ペット" より親しみ)
- 「街」 (← "サービス" より温かい)
- 「住民」 (← "ユーザー" より人間味)
- 「想い」 (← "気持ち" より深い)
- 「ふたり」 (← 飼い主とペットの絆)

❌ 避ける言葉:
- "今すぐ" "急いで" (煽り)
- "限定" "特別" (商業的)
- "稼げる" "儲かる" (ビジネス感)
- "便利" "効率" (機能訴求)
- 絵文字の連発 🐾🌿🐨 (装飾的)
```

### コピーライティングの原則

```
1. 「、」で繋ぎ、「。」で終わる (静かな余韻)
2. 「？」より「。」を選ぶ (押し付けない)
3. 改行で呼吸を作る
4. 余白の美 (情報過多禁止)
5. 詩的、控えめ、温かい

例:
❌ 「今すぐ会員登録して、お得なクーポンをゲット！」
✅ 「うちの子の話で笑い合える、そんな街が、ここにあります。」
```
