## 🚨 超重要な考え方

```
Qoccaは、

❌ NOT: 「ペット向けマーケットプレイス」

として ブランド設計する。
```

## 📍 Hero Section の役割 (最重要)

### 構成 (上から下へ)

```
1. 大きなコピー (感情)
   「うちの子との時間を、
    ちゃんと残せる場所。」

2. 小さい説明文 (機能理解)
   「ペットを愛する人たちが集まる、
    コミュニティ＆マーケットプレイス。」

3. CTAボタン (参加導線)
   「この場所に参加する」 等
```

### Hero に必要な要素

```
✅ 必須:
- 感情を喚起する大きなコピー
- 何のサービスか伝える小さい説明文
- 自然なCTA

❌ NG:
- "今すぐ" "急いで" の煽り
- 機能の羅列
- 商業的すぎる表現
- 説明文の欠如 (世界観だけ)
```

## 🎭 サービス説明の見せ方

### ❌ NG: 普通の機能一覧

```
- 出品できます
- 購入できます
- 依頼できます

→ 説明感が強すぎる
→ 興奮を呼ばない
→ "メルカリと同じやん" と思われる
```

### ⭕ 良い: 感情から機能へ橋渡し

```
「思い出を形に残す」
  ↓
  → 似顔絵
  → オーダー作品
  → 記念グッズ

「うちの子との暮らしを共有する」
  ↓
  → 投稿
  → 写真
  → コミュニティ

「ペット好きと繋がる」
  ↓
  → クリエイター
  → オーナー
  → 出品者
```

→ "なぜそれが必要か" の感情を先に提示
→ その後に具体的な機能を見せる
→ 感情 → 機能 の順番が絶対

## 💬 コピーライティング原則

### Qoccaの本質

```
Qoccaは、

❌ 「機能を売るサービス」
✅ "感情を叶えるために機能があるサービス"

として作る。
```

### CTA (ボタン) の方向性

```
⚠️ CTA は消さない、でも営業感を消す。

❌ NG:
- 今すぐ購入
- 無料登録
- 出品はこちら
- お申し込み

⭕ 良い:
- この場所に参加する
- うちの子を残す
- 誰かの暮らしを覗いてみる
- 思い出を形にする
- 街を歩いてみる
- 住民になる
```

→ 動詞の質が違う
→ "購入" "登録" → ✗ (商業的)
→ "残す" "参加" "覗く" → ⭕ (感情的・体験的)

### コピーの作り方

```
ステップ1: 感情を1行で表現
ステップ2: その感情がなぜ起きるか1行で
ステップ3: その感情を解決する方法 (機能) を提示

例:

【感情】
"うちの子との時間は、二度と戻らない。"
↓
【共感】
"だから、ちゃんと残しておきたい。"
↓
【機能】
"Qoccaなら、写真・作品・コミュニティで、
 すべての瞬間を保存できる。"
```

## 🎯 UIで重要な King の核心

```
"説明を消す" のではなく、
"説明の順番を変える"

これが King の核心的な洞察。
```

### 順番の重要性

```
❌ 悪い順番:
1. 機能の説明 (退屈)
2. 感情の喚起 (遅すぎる)
3. 行動を促す (もう離脱した)

⭕ 良い順番:
1. 感情の喚起 (引き込む)
2. 共感の確認 (深める)
3. 機能の理解 (合点する)
4. 行動を促す (自然な流れ)

→ 映画の予告編と同じ構造
```

## 🔧 実装での具体的な指針

### Hero Section の改善

```
現状 (静けさRedesign 後):
- 写真ローテーション (14/10/10/10/10/10/14秒)
- キャプション: 「うちの子を愛してる人が集まる街。」

【King の新指示で改善する場合】

大きなコピー (上):
「うちの子との時間を、
 ちゃんと残せる場所。」

小さい説明文 (下):
「ペットを愛する人たちが集まる、
 コミュニティ＆マーケットプレイス。」

→ "場所" だけでなく "何ができるか" を明示
→ 機能理解を 7秒で達成
```

### About Section の改善

```
SECTION 2-3 (Today's Moments + Town Map) の間に
"What is Qocca" 的なセクション追加検討:

「Qoccaでできること」
というタイトルではなく、

「思い出を形に残す」 → クリエイター作品
「暮らしを共有する」 → コミュニティ
「ペット好きと繋がる」 → 出会い

→ 感情で誘導しながら機能を理解させる
```

### Town Map (SECTION 3) の改善

```
現状:
○ 広場 = コミュニティ
□ 商店街 = クリエイター出品
◇ 案内所 = 施設マップ
△ 展示場 = ギャラリー

→ "街" のメタファーは維持
→ ただし "何ができるか" をもっと明確に
→ 各カードに 1-2語の機能ラベル追加検討
```

### CTA Section (SECTION 6) の改善

```
現状:
"あなたの家の窓辺を、誰かに見せませんか。"
[Qoccaの住民になる]

【改善案】
"あなたの家の窓辺を、誰かに見せませんか。"

その下に補足:
"ペットを愛する人たちが集まる、コミュニティ＆マーケットプレイス。"

[この場所に参加する]
or
[うちの子を残す]
or
[街を歩いてみる]
```

## 🚨 デザイン作業時の判断基準

### 新しい要素を作る時、必ず自問

```
Q1. これは何を伝えるか?
   - 感情? → 大きく、ゆっくり
   - 機能? → 明確に、簡潔に
   - 行動? → 自然に、押し付けず

Q2. ユーザーの感情の段階は?
   - 0-3秒: 感情段階 → 詩的・控えめ
   - 3-7秒: 理解段階 → 機能を簡潔に
   - 7-15秒: 共感段階 → 体験を提示
   - 15秒+: 行動段階 → 自然な誘導

Q3. 商業感はないか?
   - "今すぐ" "急いで" → NG
   - "無料" "お得" → NG
   - "参加" "残す" "覗く" → OK

Q4. 機能を消してないか?
   - 世界観だけになってないか?
   - "何ができるか" 伝わるか?
   - 7秒以内に機能理解できるか?
```
